In the YouTube app on a supported smart TV, open Settings and Parent code, then follow the setup for a four-digit code. The code restricts signed-out viewing, access to older household members' accounts and account removal on that TV. It does not approve videos or set a viewing allowance. You still need the intended child's profile and a separate content rule.

## Set the code on the television

Use the YouTube app's settings on the TV itself. Choose Parent code and complete the setup prompts. Keep the code with the adults who manage viewing.

The parent code is not the password for the Google account. It is a local protection in the television experience. Setting it on this television does not apply the same code restriction to every phone or tablet.

Google does not provide a complete model-by-model compatibility list in the general instructions. If the menu is missing, update the television's YouTube app and consult the device's supported version before assuming every set has identical controls.

## Test the routes it protects

From the child's viewing flow, try to switch to an adult account, view while signed out and remove an account. The documented protected actions should ask for the code.

Then return to the child's intended profile. A working account gate is only one part of the setup. Look at the actual available videos as well.

Do not reset or remove the family accounts simply to test the code. Checking whether the prompt appears is enough.

## Set a content rule separately

Use the child's supported YouTube Kids or supervised experience. Manage its settings through the appropriate parent account and app. A television may display a child experience whose detailed controls are easier to manage on a phone.

If your rule requires a small list of parent-selected videos, confirm that the television is opening that experience, rather than regular YouTube under an unrelated account. The [control guide](/guides/control-what-child-watches-on-youtube) explains the available models.

## Time limits need their own check

A limit on a child's Android phone is not evidence that the TV will stop at the same time. Review the television's own supported controls or use an adult-managed session.

The [time-limit guide](/guides/youtube-time-limit-for-kids) helps separate app timers, device schedules and family rules. For occasional viewing, agree on one episode and keep the remote with the adult.

## Casting and other television apps

Casting can introduce another controller, account or playback session. Test the method your family actually uses, including a caregiver sending a video from a phone.

The YouTube parent code also does not lock every streaming app or the TV's home screen. Those are television or operating-system settings.

LittleLoop does not currently provide a smart-TV app in this launch. Its mobile player requires parent-selected content, uses YouTube's official embed, may show platform ads and is not affiliated with Google or YouTube.

For a straightforward shared-screen arrangement, consider the [no-app viewing routine](/guides/no-app-ways-to-control-what-child-watches). A television watched together can remain a practical option without building a complex control system.
