Choose a limit that matches the device and the rule. The YouTube Kids timer ends a single session. Apple Screen Time and Google Family Link can enforce recurring app or device limits. A kitchen timer gives a warning but needs an adult to stop playback. Test a short limit before relying on it, including whether the child can continue in a browser or on a second device.

## One session or a daily allowance?

A 20-minute session and a 20-minute daily allowance answer different questions. A session timer starts when you begin it. A daily limit accounts for use during the day according to the platform's rules. Decide which one you mean before setting anything.

YouTube Kids has a built-in timer for a single sitting. In its parent settings, pass the parent check, choose Timer, set the duration and start it. The child sees an end-of-time notification when it expires. This is useful on a handed-over device because you can set the session at the same moment you choose the video.

Use a custom parent passcode if your child can answer the arithmetic question. A control that the child can dismiss does not enforce the family rule.

## An iPhone or iPad used every day

For a child's Apple device managed with Family Sharing, open Screen Time for that child. Add an App Limit for the relevant video app, choose the duration and days, and enable blocking at the end of the limit where offered. Protect Screen Time settings with a passcode the child does not know.

Check Always Allowed and Downtime as well. A device can have an app limit and a separate bedtime schedule. Guided Access offers a time limit for a temporary session on an adult's phone, but is not a replacement for the child's recurring daily rules.

Opening YouTube in a browser is another route. Review both app and web access rather than assuming the native app limit covers every way of watching.

## An Android device or Chromebook

In Family Link select the child, then Screen time, Time limits and App limits. Choose the app, set the permitted time and save. A device-wide daily limit is a different setting.

Google notes that app limits support eligible Android and ChromeOS versions and cannot be placed on system apps. Device daily limits and app limits also have different cross-device behavior. Check the current account's device list before treating one allowance as a household-wide total.

The [Android setup guide](/guides/control-youtube-on-android) covers the relationship between the child's account and the device.

## Test the stopping point

Set a two-minute test session with an adult present. Let a video run past the limit. Try the usual exit and reopen flow, then check the browser and any second device the child routinely uses.

Do not test by asking a child to find every possible workaround. The goal is to confirm the normal family setup works. If it does not, write down whether the issue is an account mismatch, a dismissed limit or a different app.

## Make the limit understandable

A timer can stop in the middle of a story. When possible, choose a video that finishes before the allowance does. Tell the child which video is last before starting it. [Disabling autoplay](/guides/stop-youtube-autoplay-for-kids) helps preserve that pause.

For a child who finds endings difficult, combine the setting with a predictable handoff. The guide to [ending screen time](/guides/end-screen-time-without-tantrum) explains the routine. A functioning timer is useful, but the conversation about stopping still belongs to the family.
